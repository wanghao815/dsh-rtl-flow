## 事件记录格式

- Task：目标与关联步骤。
- Input：原输入、版本与配置。
- Model / Agent：实际可取得的模型、框架和插件版本，缺失写未记录。
- Attempts：真实尝试/调用的计数范围、原生/外层耗时、资源；Token 与费用缺失写未记录。
- Failure：首个症状、影响及原始失败产物。
- Root Cause：已证实机制与仍待确认项。
- Human Intervention：用户决策、补件、手工修复或无；不把决定当作修复。
- Resolution：改动、同配置复验和剩余范围。
- Generalization：未验证 / 同场景复跑 / 跨新场景实测，注明对应证据。
- Evidence：失败、修复、复验与决定的可核查链接。
