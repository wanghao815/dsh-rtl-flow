# 物理实现与同版验收

ASIC 目标逐平台选定库、技术文件、RC、宏、规则与角。工艺无关功能证据可以共享；每条实际物理路线分别归档。另一平台缺材料、失败、不适用和未运行分开记录。不要把一种 PDK 的 SRAM 视为另一种工艺的可用宏。

## 扩大规模前的小试

选一个关键 leaf、代表性互连与真实存储边界，实跑综合到布线和物理检查。统计分层实例、按复用次数展开的逻辑/物理单元、网与边界引脚，分别报告标准单元面积、宏外框和 die 面积。宏数量小仍可能对应数千万标准单元和大量宏内部几何。

规模较大或重复结构较多、需要选择实现粒度时，保留或建立全平铺基线，并与关键单元或较大模块硬化候选比较。计入首次硬化、顶层布线/供电通道、pin access、跨宏 setup/hold、宏内部/边界验收，以及面积、时序、布线、运行时间和峰值内存。根据实际目标与测量建议方案；只在有依据时更改已确认的实现策略。小设计或已确定路线的局部任务不必额外运行全部候选。

## 检查点链

综合 → floorplan/PDN/I/O → placement → CTS/hold → global route → detailed route → 填充/最终输出 → RCX → STA/物理检查。每个阶段保存实际输入/输出及日志；依赖失败阻止后续启动。图件、网表、数据库、SDC、RC、库角与宏视图通过摘要绑定。

最终文件按流程实际支持交付 GDS、DEF、网表、SDC、SPEF、数据库（例如 ODB）及报告。不是每个流程都生成相同文件名。CTS 图可来自祖先 CTS 数据库，但必须明确来源；不能称作最终版本的时钟几何。输出系统/微架构图、实际放置布线全图、关键金属局部、CTS 拓扑/实际走线及可编辑源。

按实际进度展示平面规划、宏与标准单元放置、布线全貌及局部金属、时钟树。每张图注明设计层级、平台、阶段、检查点、比例和主要对象，来自真实数据库或版图。实现粒度调整或物理优化时提供前后对应视图，尽量使用相同视角与比例，说明约束差异，并列面积、时序、单元数量及运行成本。只完成放置时展示放置结果，不以示意图代替尚未完成的布线结果；图片帮助复核，技术通过仍由对应检查判定。

| 检查 | 必需核对 |
| --- | --- |
| 综合/等价 | 同一动态实现、状态与接口保留、宏真实实例、无意外展开/常量化/黑盒；层次切分和 ECO 有适用等价 |
| STA | 原 SDC、真实提取寄生、传播时钟、setup/hold、WNS/TNS、负端点、未约束端点、I/O、宏弧、寄生覆盖、原始 cap/slew/fanout；不得用打印舍入把负裕量称为零 |
| 多角 | 标准单元、宏、RC 均匹配的实际角；没有材料的角保留缺项 |
| DRC | 固定 deck、规则及真实图形覆盖；宏内部、宏边界、顶层分别计；层次定义数量与平面出现次数不能混算 |
| LVS | 提取/参考网表来源、单位/DBU、器件种类、参数与 nf、端口和电源；blackbox/被排除器件清楚列出，验证物理断线与参数负例 |
| Antenna | 阈值、gate/diffusion 面积、宏端点及层覆盖；已知违规能检出。零项但没有模型记覆盖不足 |
| Power/PDN | 实际 VDD/VSS 连通、负载和活动条件、两轨求解；静态 IR、活动功耗、动态 IR、EM 分开报告 |

规则适配、器件分类或分块/层次执行变更需来源依据与资格验证：正反例、实际宏、边界窗口，并与原报告逐类/几何/出现次数对照。减少标记数量不证明适配正确。LVS 对称排除器件只证明该受限比较，不能升级成完整内部物理 LVS。

## 修复和最终判定

先保留失败源、原始电气清单、路径和几何，再按真实驱动/负载/电源连接修复。区分数据网与真实时钟，按实际单元类型识别二极管。ECO 后重提寄生并重跑受影响功能、等价、原 SDC 时序及物理检查；不能拼接不同候选各自最好的结果作为一个通过版。

公开规则通过只说明已验证的范围。缺模型、未运行、超时和仍失败项出现在覆盖表和交付中；试验流程不等于代工厂制造签核。CLI audit 解析已支持格式的原始报告并核对指标、文件摘要和检查点；未知格式保持未支持。规则、模型、器件覆盖及工程适用性仍需工程师复核，自动解析不构成完整物理签核。
