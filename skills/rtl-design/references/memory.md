# 存储接口与容量专题

进入条件：寄存器文件、推断 RAM、缓存或 SRAM/ROM 接口。必要输入：逻辑容量、物理容量、使用量、端口数、读写延迟、冲突规则、掩码、有效极性、地址单位、布局和复位保留策略。

处理：分离 TB 预装/观察与可综合装载/访问逻辑，写独立地址与布局规范。验证读响应、写入副作用、逐字节掩码、read-during-write、越界、bank/lane 对应及任务有效区。缓存/ECC 等特性仅在本项目承诺时增加，并明确一致性/错误路径。

产物：存储合同、wrapper、打包/解包和独立已知字节例、全地址/掩码/边界测试、综合 memory 结构统计及真实输出回读。

判据：所有有效访问符合端口和带宽，数据/标签/掩码对齐，未初始化区域不被误当有效输入，reset 按合同保留/清除。地址限制不代表物理缩容，行为模型通过不代表真实宏接通。失败优先检查地址单位、字节序、符号/位宽、读延迟和 bank 拼接，避免增加存储时钟或时分访问来偷偷改变带宽。
