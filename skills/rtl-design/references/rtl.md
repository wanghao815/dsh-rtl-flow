# 通用 RTL 生成与集成

只实现当前确认的接口、配置和行为。先生成最小关键 leaf，用实际仿真和综合前端核对 SV 语法，再扩展层次。复用已验证核心，避免为集成另写一套功能近似实现。

## 编码约束

- 明确模块端口、参数合法范围、signed/unsigned、表达式扩展及截断。乘法结果、移位量、计数器和地址分别计算所需位宽；非 2 的幂深度不能靠自然回绕。
- 组合块完整赋值；时序块使用非阻塞赋值。保持状态单一驱动，避免 latch、隐式网、组合环和未约束跨域连接。
- 明确优先级：reset、flush/abort、stall、接受和提交。valid=0 时哪些字段无意义、哪些状态仍必须保持写实。
- 数据、标签、掩码、异常、first/last、模式和有效性遵守同一个传输条件。ready/valid 回压时保证保持，不丢失、重复或重排。
- 参数化只覆盖已承诺范围。宽度 1、深度 1、非 2 的幂、全零参数和最大值依项目范围显式处理；不要自动宣称任意参数均有效。
- 可综合数据通路不使用 real/shortreal、软件浮点或 TB 文件 I/O 代替硬件。验证专用绑定、观察接口和故障注入与 DUT 清单分离，不能靠宏定义改变真实计算语义。
- RAM 推断、寄存器阵列和真实宏是不同实现。显式 wrapper 隔离端口/极性/读延迟，避免综合把必需宏展开、常量化或留成缺视图黑盒。

## 按设计类型选择机制

| 类型 | 关键实现和检查 |
| --- | --- |
| 控制/总线寄存器 | 状态转移、握手、错误响应、字节选通、副作用只触发一次、复位值、保留位 |
| FIFO/流处理 | full/empty、计数守恒、同时 push/pop、回压保持、wrap、长突发、可配置延迟 |
| 仲裁/互连 | 请求与 grant 一致、互斥、锁定、ID/响应路由、公平性及进度假设 |
| 算术/DSP | 原生操作数和中间位宽、精度、舍入节点、反馈、II、溢出/下溢、数值域 |
| 存储系统 | 地址单位、冲突、掩码、读写时序、ECC/异常（若有）、真实物理容量与宏接线 |
| CPU 子模块 | hazard、旁路、flush、异常、提交、停顿、顺序一致性和架构状态更新 |
| 多时钟模块 | CDC 结构、同步器、异步 FIFO Gray 约束、域间复位释放及 RDC；仿真不能代替亚稳态分析 |

## 清单与结构检查

仿真、综合、形式使用可追溯的同一源与参数定义；列出验证 harness 或形式抽象的差异。插件审计支持每行一个项目相对源码路径的 manifest；工具自己的 `-f`/include/define 语法应另由适配入口处理并纳入摘要。

每个 leaf 和顶层核对 latch、未解析模块、驱动冲突、memory 实现、实际状态数、算子/宏数量及输出是否意外常量化。动态模式必须保留真实共享逻辑；单模式时序视图不能代替动态综合实现。修复仿真可观测接口引起的假环后，复跑真实 DUT，不能为消除告警改变数据通路。

早期时序探针必须包含真实反馈、I/O 条件和目标库。若时序与合同冲突，保留路径、源 SDC、估算/提取类型、失败版和选项影响；增级、降 II、交错状态或降低功能属于合同变更。
