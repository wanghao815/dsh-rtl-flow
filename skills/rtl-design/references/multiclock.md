# 多时钟与复位域专题

进入条件：存在多个异步/相关时钟、跨域控制/数据，或异步复位释放。必要输入：域表、时钟关系、频率范围、复位源/释放、跨域信号清单、稳定窗口和允许丢失/合并语义。

处理：逐条选择单 bit 同步、toggle/握手、Gray 指针或异步 FIFO 等结构，分析多 bit 一致性、脉冲宽度、复位重汇聚与域间复位先后。SDC 的时钟组、false path、最大延迟/偏斜依据真实结构制定，不能泛化屏蔽所有跨域路径。

产物：域/复位图、跨域清单、同步结构与属性、CDC/RDC 检查、异步相位/频率/复位顺序测试、相关形式性质和约束依据。

判据：结构与协议符合跨域合同，数据一致、事件计数和容量安全，复位释放无非法外部副作用。数字仿真不能证明亚稳态安全；没有可用 CDC/RDC 工具或模型时明确 unsupported 与人工结构审查范围，不把随机时钟测试通过当作完整 CDC 验收。失败先区分结构、跨域协议、约束和采样问题，不能简单多加一拍替代协议分析。
