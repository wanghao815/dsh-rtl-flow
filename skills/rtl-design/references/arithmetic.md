# 算术与数值专题

进入条件：整数、定点、浮点、归约、近似算术或状态反馈参与功能。必要输入：格式/编码、运算图、位宽、操作顺序、舍入/截断、溢出/下溢/异常策略、II、反馈与输出合同。

处理：先建立独立 reference 和手算例，再按真实项数证明每段位宽及误差边界；确定各舍入节点，分开数值域与域外控制。对反馈使用最新状态，避免流水寄存重复捕获。定向覆盖零、抵消、符号、边界、舍入中点和 subnormal（若支持）。

产物：numeric_contract、参考模型、预算/域证书（若采用）、primitive 与严格用例、关键数据通路图、同实现的结构和反馈时序证据。

判据：精确比较或事前固定的输入相关误差界逐点满足，严格规范例另验；不因失败放宽阈值或改变归约/舍入图。失败先定位编码、符号扩展、对阶、舍入、反馈和输入对应关系。资源与周期冲突附实际路径返回架构评审，不自动增加流水或交错状态。
