# 工具、库与宏的实际就绪

先检查已有工具、来源和项目环境，复用有证据且匹配的组合。尊重用户指定的原生、容器或远程路线，不因本机问题自动改平台。Python 隔离方式由项目确定；若用户要求 Miniconda，核实发行版并使用独立环境，不替换成 Anaconda。

记录可执行路径、版本/提交、宿主 OS/架构、构建选项、补丁、求解器、Python 依赖、标准单元、PDK、RC、规则和宏视图。安装、工具启动、功能测试、小流程贯通、真实设计通过是不同状态。

开源 ASIC 参考工具组合：SystemVerilog、Verilator/cocotb、Yosys/ABC、SBY/EQY、OpenROAD/ORFS/OpenSTA、KLayout/IC Netgen。它是可替换的适配方案；现有商业工具与项目已验证流程优先按项目选择复用。当前插件不会自动安装 EDA 工具。

| 最小检查 | 判据 |
| --- | --- |
| 编辑/构建/Python | 新终端能进入正确环境，依赖导入与本机编译通过 |
| 仿真 | 非恒定输出小模块、时钟/复位/逐拍检查；故意错误由指定断言检出 |
| 综合映射 | 实际综合入口接受所用 SV，寄存器/单元/网表非空且结构合理 |
| 性质证明 | 约束非空、cover 可达；正例证明与错误版本反例均可查 |
| 等价 | 语义相同通过；功能改变产生不等价，不把超时记成负例成功 |
| 小 RTL-to-GDS | 匹配平台实际通过综合、放置、CTS、布线、RCX 和 STA |
| DRC/LVS | 正例与实际几何/连接错误负例，核对规则和器件覆盖 |
| 真实宏 | 原模型读写/掩码/延迟，全视图匹配，端口/电源和实际小顶层接通 |
| 生成器（若使用） | 实际合法配置生成并核对视图，不能用仅编译成功或下载目录宏替代 |
| 干净终端复跑 | 依赖、PATH、插件与补丁均在锁定入口中，没有隐藏交互步骤 |

只打印 help/版本不足以就绪。检查真正被调用的能力，例如综合器是否支持流程依赖的 Tcl，Netgen 是否是 IC LVS 版本，KLayout 的运行环境是否装有需要的 API。正反例须核对退出码、诊断和原始报告，不能只匹配日志里一个 PASS 字符串。

不同平台分别验证，不能将一种工艺的 SRAM 与另一种技术文件混合。视图需对齐型号、尺寸、引脚、电源、掩码、时序角和外部引用。只拥有宏的多角 Liberty 不代表标准单元和 RC 也支持全设计多角。物理规则与宏内部提取能力尽早用真实材料验证，覆盖不足登记为开放项。

换工具、PDK、OS 或主要补丁后重跑受影响的最小集合。锁定清单只是输入记录，不是通过证据。
