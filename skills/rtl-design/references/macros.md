# 真实物理宏专题

进入条件：设计使用已硬化计算模块或真实 SRAM/其他物理宏。必要输入：同版本仿真模型、Liberty、LEF、GDS、LVS 参考，端口/PG/掩码、时序角、尺寸、障碍、天线和负载模型。

处理：先检查视图一致性与合法配置，建立真实小顶层探针，核对端口、电源和实例数量。对存储用完全相同输入镜像校验摘要，经原宏模型读写并从实际 bank 回读；对计算宏核对状态/接口等价、时序和宏间连接。按展开后的实际规模估算物理验收成本。

产物：视图锁、引脚/几何报告、实际宏实例检查、同镜像回放/等价、小顶层物理探针，以及按角色绑定的 checkpoint manifest。

判据：真实实例未被展开、丢失或常量化，接口/延迟/容量满足合同，物理材料与平台匹配。宏内部、边界、顶层分别报告 DRC/LVS、天线和电源覆盖；缺内部器件/阈值模型不能记完整通过。失败保留原始视图和原规则，适配先用物理正反例资格检查，再扩大到顶层；标记减少本身不证明正确。
