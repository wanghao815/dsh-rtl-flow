# 资源、长任务、恢复和归档

实际预算格式、设备采样和前台运行入口见 [资源操作](../../../docs/resources.md)。先识别 new/adopt/modify/eco/resume，复用经审计且未失效的先决条件。完整验收、约定范围交付、实验收尾与生命周期分开记录。

在扩规模之前记录当前设备的 CPU/内存/磁盘/OS，约定每阶段墙钟、峰值内存/交换、磁盘增量、明确余量、重任务并发和重试预算。未知项保持 null/待定，先做代表性探针再估算。

分别估计一次原生步骤、首轮出图、包含复验/修复的总工期。记录估算依据与未知收敛轮数。层次布置加速不能直接外推全量 DRC/LVS 和最终收敛工期。根据实测峰值决定并发，重型详布、几何合并和 LVS 的内存会叠加。

## 长任务

- 启动前固定参数、输入、报告需要的环境及独立输出目录；检查是否已经有同一工作或等待器在跑。
- 使用宿主已有的 jobs/终端能力，遵守其取消、权限与生命周期。显式 `run --task` 在前台串行监测本次任务，不创建后台调度、隐藏等待器、自动重试或新的权限通道。
- 持续核对日志是否前进、原生阶段、已耗时间、实际产物、退出状态及资源。一个外层脚本退出零不能替代内层报告判据。
- 超限或监测失效时先保存现场并受控停止本任务的进程组，不等待人工决定才停止计算。多轮修复不收敛时按约定尝试预算停止新增尝试。随后给出已耗成本、残余问题、继续/资源调整/缩规模/范围调整/收尾的具体影响；改变资源或验收范围须有明确决定，保留原失败与未覆盖项。既有授权和预算内的诊断与修复继续推进。

## 中断与接续

先核对 PID、完整命令、工作目录、最新日志、检查点和原生退出状态，再决定复用或重启。历史“运行中”不表示现在仍在运行。当前暂停决定覆盖旧队列，明确恢复授权前不启动依赖任务。

暂停时先冻结等待器、调度和重试入口，记录最后完整结果与在途请求，然后受控退出本任务的进程，核对无自动重启。不能按进程名批量杀其他项目。内核 signal/退出码、包装 trap 的记录和检查结论分别保存；中止不记通过。

## 保存与交付

保留规格/源码/输入/版本锁、选定基线、必要失败现场及恢复依赖。派生缓存不必每轮全量复制。任何删除都须符合当前项目授权，归档建议不构成删除权限。

索引记录相对路径、来源、大小和 SHA-256；大文件可在已验证摘要和未变元数据基础上复核，新/变更文件重新计算。资料摘要只能校验，不能恢复缺失内容。区分精选报告包与含工具、PDK、宏视图、输入和检查点的可重跑备份。

交付说明改动、依据、实际检查、最关键报告、未通过/未完成/未覆盖项与下一项已授权工作。按项目约定在阶段边界交接，写出当前状态、准确入口、恢复命令、必要外部材料、停止/恢复条件与已运行后台任务。只提供已存在且验证过的命令。

## Agent 记录

重大问题沿同一事件编号保存首次失败、尝试、根因证据、用户帮助及复验。区分 Agent 错误、工具/环境限制、规格决定、正常工程收敛和交付反馈。Token、费用或人工耗时没有计量就写未记录。方法泛化区分未验证、同场景复跑、跨新场景实测；一个项目内修复成功不宣称通用正确。
